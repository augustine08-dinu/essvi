# ESSVI Internationals website

A responsive static website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — all page content and sections
- `style.css` — responsive design and styling
- `script.js` — mobile navigation, product enquiry selection and enquiry form
- `assets/essvi-logo.jpg` — cropped client logo

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension.

## Before publishing
1. Replace `REPLACE-WITH-VERIFIED-EMAIL` in `script.js` with the client's confirmed business email.
2. Add verified company address, phone/WhatsApp, and any official registration details to the footer/contact area.
3. Confirm product specifications, grades, certifications, packaging and shipping claims with the client. The current specifications section intentionally asks buyers to request confirmed batch data rather than presenting unverified figures as guarantees.
4. Replace remote Unsplash image URLs with licensed client-owned imagery if available. The page currently uses online images, so those images require an internet connection.
5. Test the enquiry form and mobile navigation on phone and desktop.

## Deploy
This is a static site and can be hosted on GitHub Pages, Netlify, Vercel, or most standard web hosting providers. Upload the contents of this folder (not the ZIP itself) to the site's public web root.
